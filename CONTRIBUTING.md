# Contributing

Thanks for taking a look. This is a public website repository, so contributions
should stay focused and respectful of the site's content ownership.

## Local Setup

```sh
npm install
npm run dev
```

Useful checks before opening a pull request:

```sh
npm run build:local
npm run audit:prod
```

## Content and Media

Do not reuse the site's copy, photos, generated images, audio, branding, or SEO
research in forks or other projects. See `CONTENT-LICENSE.md`.

## Pull Requests

Keep changes small and explain the user-facing effect. Avoid broad formatting
or generated-file churn unless it is required by the change.
